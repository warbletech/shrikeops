# Contributing

Thanks for contributing to this Warble OSS component.

## Flock home

- Community site: https://warbleoss.org
- Umbrella repo: https://github.com/warbletech/warble-army
- Full guide: https://github.com/warbletech/warble-army/blob/main/docs/cncf/CONTRIBUTING.md

## Pull requests

1. Prefer small, focused PRs.
2. Use [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`).
3. By contributing, you agree your work is licensed under **Apache-2.0** (see LICENSE).

## Security

Report privately via [SECURITY.md](SECURITY.md).

## Good first issues

Look for the `good-first-issue` label on this repo or on warble-army.
